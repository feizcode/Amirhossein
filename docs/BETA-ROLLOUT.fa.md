# انتشار بتای مربی — ۲۰۲۶-۱۰-۲۳

## به‌روزرسانی استقرار

با فراهم‌شدن دسترسی جدید، نسخه روی سرور مستقر و تنظیمات بتا فعال شد؛ مانع DNS/cURL با حل نام پویا و حفظ TLS اصلاح شد؛ یک درخواست واقعی در ۷٫۲ ثانیه موفق بود و fallback همچنان برقرار است. [گزارش دقیق استقرار](HOST-BETA-DEPLOYMENT.fa.md). مطالب «منتظر دسترسی» در بخش تصمیم زیر، تاریخچهٔ تصمیم قبلی‌اند.

## تصمیم جاری

به درخواست مالک پروژه، بررسی شرایط کاربرد کودک/سیاست دادهٔ فروشنده و تأیید انسانی بانک سؤال به کارهای آینده منتقل شدند. این تصمیم تأیید حقوقی، تأیید انسانی یا رفع ریسک نیست. در همین نوبت، مالک به علت نبود دسترسی سرور، «فعلاً فقط GitHub» را انتخاب کرد؛ استقرار و فعال‌سازی API روی سرور اصلی هنوز انجام نشده است.

این تصمیم، شرط قبلی «هیچ استفادهٔ زنده تا تکمیل هر دو تأیید» را فقط برای حالت صریح بتای GapGPT تغییر می‌دهد؛ انتشار عادی همچنان نیازمند هر دو تأیید است. اسناد آزمون قبلی شواهد تاریخی‌اند، نه وضعیت استقرار فعلی.

## کارهای آینده

- [ ] بررسی شرایط قابل‌اعمال GapGPT برای کودک، نگهداری/آموزش با داده و محدودیت صورتحساب؛ ثبت شواهد واقعی قبل از تغییر provider_terms_verified.
- [ ] بازبینی انسانی هر سؤال، جواب، راهنما و راه‌حل و ثبت نام/تاریخ واقعی بازبین؛ وضعیت فعلی prototype_checked حفظ می‌شود.
- [ ] دریافت دسترسی جدید سرور، پشتیبان تازه از داده و تنظیمات، ارتقای MariaDB بدون بازنشانی اطلاعات و آزمون بازیابی.
- [ ] فعال‌سازی و آزمون محدود API از سرور، سپس پایلوت یک‌هفته‌ای با نظارت والدین.

## قرارداد فنی بتا

مدل gpt-6-luna از GapGPT؛ رابط با عبارت «هوش مصنوعی · نسخه بتا» و هشدار امکان خطا نمایش داده می‌شود. متن ذخیره‌شده از خروجی AI متمایز است. نمره‌دهی برنامه‌ای می‌ماند و سابقه یا هویت کودک به ارائه‌دهنده ارسال نمی‌شود.

برای فعال‌سازی آگاهانه روی سرور، در تنظیمات خصوصی ai_coach باید enabled=true، beta_enabled=true و beta_acknowledged_at برابر زمان واقعی تصمیم با قالب UTC ISO-8601 باشد. provider_terms_verified تا انجام بررسی false می‌ماند. مدل و تعرفهٔ آزموده‌شده، حداکثر ۵۱۲ توکن، سقف ۱۰ درخواست و ۰٫۰۱ دلار رزرو روزانه حفظ شوند. همچنین practice_prototype_enabled=true و practice_allow_prototype_content=true برای بانک فعلی لازم‌اند. محتوای draft مجاز نیست. این تنظیمات را نباید با کل فایل local.php توسعه روی سرور جایگزین کرد.

پیش‌فرض عمومی همچنان غیرفعال است؛ اسرار در GitHub یا بسته‌ها قرار نمی‌گیرند. خطا، رد کیفیت و اتمام سقف به متن ذخیره‌شده برمی‌گردند، بدون retry پولی. غربالگری تضمین درستی ریاضی نیست. برچسب بتا و تصمیم مالک جایگزین شرایط فروشنده نمی‌شوند.
