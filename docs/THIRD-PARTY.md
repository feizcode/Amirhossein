# Third-party software

PHP dependencies and exact versions are recorded in `composer.lock`; their license files remain with `vendor/` in the deploy package. JavaScript and font versions are recorded in `pnpm-lock.yaml`.

- Slim Framework / Slim PSR-7 — MIT
- Twig — BSD-3-Clause
- Alpine.js CSP — MIT
- Lucide — ISC, with Feather-derived icons under MIT
- Vazirmatn — SIL Open Font License 1.1
- Vite — MIT (development build tool)

Upstream license notices used by the frontend are included in `licenses/`. No external CDN is required at runtime.
