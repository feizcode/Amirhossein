# استقرار روی هاست برتینا

این راهنما برای حساب `feizaiir` و زیردامنهٔ `amir.feizai.ir` است. نسخهٔ جاری روی هاست تأیید شده است؛ [وضعیت تحویل](STATUS.fa.md) را بررسی کنید.

## ساختار نهایی

```text
/home/feizaiir/amir-app/              کد، vendor، قالب‌ها، تنظیمات و بکاپ خصوصی
/home/feizaiir/public_html/amir/      فقط index.php، .htaccess، favicon و assets
```

ZIP انتشار را در `/home/feizaiir` آپلود و همان‌جا Extract کنید. محتوای `amir-app` را داخل `public_html` نگذارید. فایل‌های `docs` همراه ZIP صرفاً راهنما هستند. پوشه‌های پروژه را با ۷۵۵ و فایل‌های عمومی را با ۶۴۴ نگه دارید؛ تنظیمات و فایل‌های خصوصی را با ۶۰۰ و پوشه‌های نشست و پشتیبان را با ۷۰۰ بسازید؛ هرگز ۷۷۷ ندهید.

## PHP و دامنه

1. در Domains، `amir.feizai.ir` را با Document Root مستقل `public_html/amir` بسازید؛ گزینهٔ Share document root نباید فعال باشد.
2. اجرای **PHP 8.2 فقط برای همین زیردامنه** را در ابزار مخصوص همان دامنه تنظیم کنید. انتخاب عمومی PHP Selector حساب را تغییر ندهید.
3. برای CloudLinux/mod_lsapi، handler استاندارد `application/x-httpd-alt-php82___lsphp` فقط در `.htaccess` همین ساب‌دامین قرار گرفته است. اجرای واقعی PHP 8.2.30 و تمام افزونه‌های لازم روی این هاست تأیید شده است. اگر پشتیبانی نمی‌شود، handler درست را از برتینا بگیرید؛ انتخاب عمومی حساب را تغییر ندهید. برنامه با PHP 5.6 قابل اجرا نیست.
4. افزونه‌های `pdo_mysql`, `mbstring`, `intl`, `zlib` و `session` باید در PHP همان زیردامنه فعال باشند. نیازی به `pdo_sqlite` روی هاست نیست.
5. DNS معتبر دامنه را بررسی کنید: رکورد A زیردامنه باید به IP همین حساب (`185.88.152.198` طبق بررسی اولیه) برسد؛ رکورد AAAA ناسازگار باقی نماند. تغییر DNS را نزد سرویس مرجع DNS انجام دهید.
6. AutoSSL یا گواهی معتبر را برای `amir.feizai.ir` فعال کنید و پیش از ورود خانواده، اعتبار TLS را تأیید کنید. `.htaccess` انتقال HTTP به HTTPS را اعمال می‌کند. هشدار گواهی را دور نزنید.

برای بررسی موقت PHP فقط نسخه و وجود افزونه‌های لازم را چاپ کنید؛ `phpinfo()` عمومی نسازید. فایل آزمون را پس از بررسی حذف کنید. رفتار دامنهٔ اصلی را نیز پیش و پس از تغییر مقایسه کنید.

## دیتابیس اختصاصی

1. با MySQL Databases در cPanel، دیتابیس `feizaiir_amir` را بسازید.
2. یک کاربر اختصاصی با رمز تصادفی قوی بسازید و فقط به همین دیتابیس متصل کنید. برای اجرای معمول فقط `SELECT`, `INSERT`, `UPDATE`, `DELETE` لازم است؛ واردکردن SQL اولیه را با phpMyAdmin حساب انجام دهید.
3. `database/001-initial.sql` را **فقط در دیتابیس تازه و خالی** وارد کنید. این فایل ساختار نسخهٔ ۱، شش درس و ۱۵ منبع را می‌سازد و فعالیت، تکلیف یا گزارش نمایشی ندارد. از واردکردن مجدد آن روی دیتابیس دارای داده خودداری کنید.
4. قبل از راه‌اندازی، وجود ۶ سطر در `subjects`، ۱۵ سطر در `resources` و صفر سطر در `activities`, `assignments`, `extra_studies`, `challenges` را تأیید کنید.

## تنظیم خصوصی

فایل `amir-app/config/example.php` فقط الگو است؛ آن را با نام `local.php` در همان پوشهٔ خصوصی ویرایش کنید. مقدار `database.password` رمز اختصاصی دیتابیس است. `password_hash` باید خروجی `password_hash($familyPassword, PASSWORD_DEFAULT)` در PHP 8.2 باشد، و `app_key` خروجی `bin2hex(random_bytes(32))`. رمز خانواده و اطلاعات دیتابیس را در پیام، Git یا فایل عمومی قرار ندهید.

برای ساخت فایل روی رایانهٔ خودتان، در ترمینال خصوصی و داخل سورس پروژه اجرا کنید:

```sh
php bin/configure.php --output=work/production-config.php
```

ورودی رمز ممکن است در ترمینال دیده شود؛ این مرحله را خود صاحب حساب انجام دهد. سپس فقط خروجی را به `/home/feizaiir/amir-app/config/local.php` منتقل کنید. نسخهٔ توسعهٔ `config/local.php` را آپلود نکنید. `secure_cookies` در تولید باید `true` بماند.

دایرکتوری‌های خصوصی `storage/sessions`, `storage/backups`, `storage/logs`, `storage/cache` در اجرای نخست ساخته می‌شوند. کاربر PHP باید اجازهٔ نوشتن در آن‌ها را داشته باشد. کد برنامه، بکاپ‌ها و اطلاعات اتصال از وب قابل دانلود نباشند.

## بررسی پس از انتشار

- HTTP به HTTPS منتقل شود؛ گواهی معتبر و PHP فقط همین زیردامنه ۸٫۲ باشد.
- بدون ورود، `/` به `/login` منتقل شود و `/api/v1/state` کد ۴۰۱ بدهد.
- `/config/local.php` و `/storage/backups/…` و `/vendor/autoload.php` محتوای خصوصی برنگردانند.
- ورود، خروج، CSRF، ثبت فعالیت، تکلیف، گزارش و دانلود بکاپ کار کنند.
- دادهٔ ثبت‌شده در مرورگر دوم با ورود مجدد دیده شود.
- هیچ دادهٔ آزمایشی در شروع دفتر خانواده باقی نماند؛ آزمون نوشتن را ابتدا در محیط آزمایش جدا با پایگاه دادهٔ جدا انجام دهید.
- بازشدن صفحهٔ اصلی `feizai.ir` و تنظیم PHP آن تغییر نکند.

تغییر نسخه: ابتدا بکاپ داده و تنظیم خصوصی بگیرید، نسخهٔ تازهٔ کد و assets را جایگزین کنید و `config/local.php` و `storage` را حفظ کنید. تغییرات بعدی دیتابیس باید SQL نسخه‌دار مستقل داشته باشند؛ SQL اولیه ابزار به‌روزرسانی نیست.
