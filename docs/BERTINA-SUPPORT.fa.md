# حل‌شده با PHP 8.2؛ این درخواست را ارسال نکنید

در ۲۰ اکتبر ۲۰۲۶، اجرای PHP 8.2.30 با همهٔ افزونه‌های لازم روی ساب‌دامین تأیید و سایت راه‌اندازی شد. متن زیر صرفاً سابقهٔ تشخیص PHP 8.4 است. تمدید خودکار گواهی همچنان باید جداگانه بررسی شود.

# درخواست آماده برای پشتیبانی برتینا

موضوع: فعال‌سازی افزونه‌های PHP 8.4 برای ساب‌دامین مستقل، بدون تغییر PHP اصلی حساب

سلام،
روی حساب feizaiir و سرور server394، ساب‌دامین amir.feizai.ir با Document Root زیر ساخته شده است:
/home/feizaiir/public_html/amir

PHP عمومی حساب 5.6 است و نباید تغییر کند. با handler اختصاصی زیر، ساب‌دامین PHP 8.4.17 را اجرا می‌کند:
application/x-httpd-alt-php84___lsphp

اما PDO و افزونه‌های pdo_mysql، mbstring و intl بارگذاری نمی‌شوند. نسخهٔ 8.4 فقط فایل‌های زیر را اسکن می‌کند:
/opt/alt/php84/link/conf/clos_ssa.ini
/opt/alt/php84/link/conf/default.ini
فایل دوم هیچ دستور extension ندارد. فایل‌های pdo.so، mysqlnd.so، nd_pdo_mysql.so، mbstring.so و intl.so در مسیر ماژول‌های همین نسخه موجودند.

لطفاً برای این ساب‌دامین، PHP 8.4 و افزونه‌های لازم PDO، pdo_mysql (یا nd_pdo_mysql همراه mysqlnd)، mbstring و intl را فعال کنید؛ zlib و session نیز لازم‌اند و فعلاً فعال هستند. تنظیمات امنیتی موجود و نسخهٔ PHP سایر سایت‌های حساب حفظ شوند.

راهنمای رسمی cPanel برای این وضعیت، بررسی تنظیم php.d.location = selector در /etc/cl.selector/symlinks.rules و اعمال آن با /usr/bin/selectorctl --apply-symlinks-rules توسط مدیر سرور را توصیه می‌کند. لطفاً متناسب با پیکربندی سرور، راهکار مناسب خودتان را اعمال کنید:
https://support.cpanel.net/hc/en-us/articles/33312713115031

گواهی معتبر Let's Encrypt برای این ساب‌دامین نصب شده و تا 18 ژانویهٔ 2027 اعتبار دارد. گزینهٔ اجرای AutoSSL در پنل این حساب دیده نمی‌شود؛ لطفاً امکان تمدید خودکار گواهی این ساب‌دامین را هم بررسی کنید.

پس از فعال‌سازی افزونه‌ها، نصب جداول و آزمون نهایی برنامه از طرف ما انجام می‌شود. هیچ رمز یا توکن دسترسی در این درخواست قرار ندارد.
