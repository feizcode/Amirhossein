# طراحی دقیق رابط وب

[گالری نماها](index.html) • نوع خروجی: تصویر PNG و HTML ثابت از رابط واقعی • وضعیت: بازنمایی نسخهٔ موجود، بدون اتصال به تولید

تصاویر از `templates/*.twig`، build فعلی Vite و توابع واقعی `resources/journal.js`/`report-view.js` با state ساختگی تولید شده‌اند. کاتالوگ در SQLite حافظه‌ای نصب شده؛ اطلاعات ورود یا دادهٔ دفتر واقعی خوانده نشده است. همهٔ درخواست‌های مرورگر با مسیر محلی پاسخ داده شده‌اند. در نتیجه رنگ، فاصله، آیکن و قلم از کد فعلی می‌آیند؛ محتوای نمونه سند استفادهٔ واقعی نیست.

برای اجرای مستقل از سرور، تنها URL قلم‌های CSS کپی‌شده از `/assets/...` به مسیر نسبی همان پوشه تبدیل شده است. build اصلی URL ریشه‌ای دارد در حالی که فایل‌ها داخل `public/assets/build/assets` هستند؛ این ناسازگاری محلی در TASK-11 ثبت شده است. CSS و تنظیم Vite اصلی تغییر نکرده‌اند. تصاویر مرجع با قلم صحیح بارگذاری‌شده ضبط شده‌اند؛ وضعیت بارگذاری قلم سایت تولید دوباره بررسی نشده است.

ارتفاع تصویر به اندازهٔ کامل محتوا است و نسبت PNG همان عرض ضبط‌شده است. گالری تصویر را با حفظ نسبت نمایش می‌دهد. هر HTML snapshot به CSS و فونت محلی داخل `assets/` ارجاع می‌دهد؛ کد اجرایی برنامه و فرم‌های قابل ارسال از آن حذف شده‌اند. دکمه‌های درون نما ثابت‌اند و عمل ذخیره یا دانلود واقعی انجام نمی‌دهند.

سیاست اختلاف: برای بازتولید دقیق نسخهٔ حاضر، سورس و build هش‌شده در [sources.json](../../sources.json) مبنا هستند. وایرفریم ترتیب اطلاعات را مشخص می‌کند؛ در اختلاف جزئی فاصله و رنگ، snapshot فعلی شاهد رفتار موجود است. تغییر عمدی طراحی باید نسخهٔ PRD/تصمیم مرتبط و snapshot تازه داشته باشد.

گالری، ماهیت نمایشی مربی و نشان‌ها را حفظ می‌کند. برنامه‌ریز هفتگی موجود در فایل‌های موقت پروژه در این مجموعه به‌عنوان قابلیت عرضه‌شده نشان داده نشده است.
