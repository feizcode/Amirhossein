# سیستم طراحی کشف

این سند و [tokens.json](tokens.json) وضعیت نهایی cascade را توصیف می‌کنند. [components.html](components.html) نمونهٔ محلی با CSS و قلم واقعی برنامه است؛ نمونه دادهٔ واقعی یا عمل ذخیره ندارد. منابع اصلی: `resources/design.css`، سپس `resources/app.css` و font imports در `resources/app.js`. در نسخهٔ قابل‌حمل فقط URL قلم‌ها نسبی شده است؛ [روش تولید نماها](../app-web-design/README.md) و TASK-11 این تفاوت را ثبت می‌کنند.

## اصول و توکن‌ها

جهت RTL، طرح روشن، متن قابل شکستن و سلسله‌مراتب ساده. رنگ تنها حامل معنا نیست؛ پیشرفت کسر متنی و تکلیف برچسب وضعیت دارد. متن کاربر escape می‌شود. استفاده از فونت و assets بیرونی برای نمایش گالری لازم نیست.

| گروه | مقدار مشاهده‌شده |
|---|---|
| متن پایه | ۱۴px / line-height 1.8؛ پاراگراف 1.9 |
| عنوان اصلی | ۳۲px دسکتاپ؛ ۲۸px زیر ۹۰۰؛ ۲۶px زیر ۶۰۰ |
| عنوان بخش/کارت | ۲۰px / ۱۵px؛ وزن ۵۰۰ |
| متن کوچک/ریز | ۱۲px / ۱۱px؛ caption پیشرفت ۱۰px |
| ورودی فرم | متن ۱۶px، حداقل ارتفاع ۵۶px؛ textarea حداقل ۱۲۰px |
| شعاع | کارت ۱۲px؛ فرم/پوسته ۲۸px؛ دکمهٔ گرد ۹۹۹px؛ تب ۸px |
| عرض و فاصله | پوسته حداکثر ۱۲۸۰px؛ بدنه دسکتاپ ۲۰px؛ محتوا ۲۴px؛ فاصلهٔ شبکه ۱۶px |
| حرکت | تغییر رنگ/سایه ۱۴۰ms؛ در prefers-reduced-motion حذف می‌شود |

این‌ها مقادیر رابط موجودند، نه مقیاس انتزاعی جدید. توکن JSON خروجی مستند است و به‌صورت خودکار به build برنامه متصل نشده است.

## قرارداد اجزا

| جزء | قرارداد و حالت‌ها | محل مرجع |
|---|---|---|
| Top bar و role switch | نام، دو بخش با aria-pressed، خروج؛ wrap در عرض کم | templates/app.twig |
| Navigation | یک aria-current=page؛ چهار مقصد هر بخش؛ راست در دسکتاپ و بالا در موبایل | journal.js: render |
| Primary / secondary button | عمل اصلی پُر، ثانویه خطی؛ hover/active/focus/disabled | design.css و app.css |
| Field | label، مقدار، required، خطای فارسی؛ readonly تاریخ در ویرایش گزارش | journal.js: formView |
| Progress | role=progressbar، aria-valuenow برابر تعداد و aria-valuemax برابر کل؛ درصد و کسر متنی | journal.js: progress |
| Story / timeline | تاریخ، درس، منبع، متن امن، عمل ویرایش در محل مجاز | journal.js: storyEntry |
| Task row / urgent | موعد، درس، وضعیت؛ انجام/برگرداندن برای کودک و ویرایش برای والد | journal.js: taskList/taskRow |
| Report | بازه، چهار شمارنده، جدول و فهرست‌های جدا؛ حالت خالی | report-view.js |
| Notice / error | اعلان aria-live و خطا role=alert؛ شکست ذخیره فرم را نمی‌بندد | app.twig و journal.js |
| Future card | برچسب صریح پیش‌نمایش؛ هیچ وعدهٔ اتصال فعال | journal.js: aside |
| Backup download | تاریخ، اندازه و لینک احرازشده؛ فایل خصوصی | journal.js: backupView |

## رفتار واکنش‌گرا

| عرض | چیدمان |
|---|---|
| بیشتر از ۹۰۰ | rail به عرض ۱۱۲px؛ محتوای دو ستون با aside به عرض ۲۳۲px؛ درس‌ها سه‌ستونی |
| ۶۰۱ تا ۹۰۰ | rail به عرض ۹۶px؛ محتوای اصلی تک‌ستون و aside شبکه‌ای؛ درس‌ها دوستونی |
| حداکثر ۶۰۰ | بدنه بدون padding خارجی و پوسته بدون شعاع؛ nav چهارستونی؛ rail compose پنهان؛ درس/فرم تک‌ستون |
| حداکثر ۳۶۰ | فاصلهٔ افقی محتوا ۱۲px و padding فرم ۱۶px |

ارتفاع پایهٔ دکمه ۴۰px و قاعدهٔ عمومی موبایل ۴۴px است؛ قواعد اختصاصی بعضی دکمه‌ها ارتفاع کوچک‌تر دارند. بنابراین ادعای یکسان‌بودن هدف لمسی همهٔ کنترل‌ها درست نیست؛ بازبینی در TASK-06 آمده است.

## دسترس‌پذیری و تحویل

وجود label، focus، aria-current، اعلان و احترام به reduced motion از کد احراز می‌شود. انطباق جامع با استاندارد، کنتراست همهٔ حالات، ترتیب خواندن صفحه‌خوان و همهٔ اندازه‌های هدف لمسی هنوز ممیزی نشده‌اند. خطا را فقط با رنگ بیان نکنید؛ رشته‌های طولانی و تغییر قلم fallback را بازبینی کنید.

مبنای تحویل به توسعه: [PRD](../../product/PRD.md)، [وایرفریم](../../product/wireframes/index.html) و [نماهای دقیق](../app-web-design/index.html). اگر CSS تغییر کرد، توکن‌ها و تصاویر نیز دوباره از همان نسخه استخراج شوند.
