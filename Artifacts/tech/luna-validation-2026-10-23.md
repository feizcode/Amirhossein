# نتیجهٔ آزمون Luna — ۲۰۲۶-۱۰-۲۳

این سند تکمیلی است و اسناد معماری قبلی را بازنویسی نمی‌کند.

## استقرار سرور

پس از دریافت دسترسی جدید، نسخهٔ بتا مستقر شد و تنظیمات API فعال شدند؛ داده‌های قبلی حفظ و مجوزهای موقت پایگاه محدود شدند. پس از تشخیص مشکل DNS داخلی cURL و اصلاح با رکورد A پویا و حفظ TLS، یک درخواست واقعی از هاست به GapGPT در ۷٫۲ ثانیه با source=ai/completed موفق شد. fallback خطاها حفظ شده است. [گزارش استقرار و اقدامات باقی‌مانده](../../docs/HOST-BETA-DEPLOYMENT.fa.md). وضعیت «منتظر دسترسی» در بخش بعد، مربوط به تصمیم قبلی است.

## تصمیم بتا پس از ارزیابی

مالک خواست بررسی شرایط سرویس و تأیید انسانی به آینده موکول شوند؛ حالت بتای صریح با برچسب «نسخه بتا» و بدون تغییر صوری وضعیت تأیید پیاده‌سازی شد. [پیگیری انتشار](../../docs/BETA-ROLLOUT.fa.md). به انتخاب بعدی مالک فعلاً فقط GitHub به‌روز می‌شود؛ API و سرور اصلی هنوز فعال/ارتقا داده نشده‌اند.

## وضعیت

آزمون مستقل از runtime با شناسهٔ فروشنده `gpt-6-luna` در GapGPT؛ ۳۲ سؤال، دو حالت راهنما و توضیح، بدون دادهٔ کودک. هیچ تغییری در تأیید بانک یا فعال‌سازی اتصال اصلی انجام نشده است.

| معیار | نتیجه |
|---|---|
| درخواست کامل | ۶۴ از ۶۴، HTTP 200 / stop |
| زمان | میانگین ۴٫۱۹، میانه ۳٫۹۱۵، p95 nearest-rank ۶٫۵۲، بیشینه ۸٫۶ ثانیه |
| هزینهٔ گزارش‌شدهٔ API | ۰٫۰۰۳۶۲۷۲ دلار؛ نه صورتحساب مستقلاً تأییدشده |
| راهنما | ۲۹ قبول، ۲ مرزی، ۱ مردود |
| توضیح، معیار حداکثر دو جمله | ۲۹ قبول، ۳ مردود |
| مجموع کیفیت | ۵۸ قبول، ۲ مرزی، ۴ مردود |

موارد مهم: یک راهنما قطعهٔ زبان سیریلیک داشت؛ یک توضیح با وجود جواب نهایی درست، عبارت تقسیم غلط نوشت؛ دو توضیح صرفاً جواب بودند. دو راهنما بیش از حد قوی‌اند. بنابراین نتیجه «نامزد فنی بهتر برای ادامه، نه تأیید تولید متن زندهٔ بدون بازبینی» است.

## پیاده‌سازی اتصال و کنترل‌های فنی

اتصال آزمایشی Luna در `src/AiCoach.php` با ویژگی‌های زیر پیاده‌سازی و با ۳۳۱ آزمون شبیه‌سازی‌شده (mock) اعتبارسنجی شد:
- ارسال پارامترهای مشخص: `model=gpt-6-luna`، `max_tokens=512`، بدون تحمیل reasoning_effort؛
- پذیرش نام مدل برگشتی تنها از فهرست مجاز (`gpt-6-luna` و `openai/gpt-6-luna`) و ثبت مدل واقعی برگشتی؛
- تطبیق هزینه و توکن با تعرفهٔ ثبت‌شدهٔ فروشنده؛
- پالایش خروجی برای رد کاراکترهای غیرفارسی/عربی (سیریلیک، تایلندی، لاتین)، رد نشانی‌های خام لاتک و مارک‌داون؛
- فیلتر ابتدایی افشای عدد جواب برای راهنما و شرط وجود استدلال/عملیات برای توضیح (با حفظ این اصل که غربالگری سطحی جایگزین ارزیابی معنایی نیست)؛
- بازگشت امن به متن تأییدشدهٔ ذخیره‌شده در صورت هرگونه خطا، عدم تطبیق یا رد کیفیت؛ بدون تلاش مجدد پولی؛
- وضعیت اتصال در محیط محلی و پیش‌فرض‌ها همچنان غیرفعال (`enabled=false`) و نیازمند بررسی شرایط سرویس (`provider_terms_verified=false`) و تأیید انسانی محتواست.

جزئیات، شاهد نقل‌قول و محدودیت‌ها: [گزارش کامل](../../docs/LUNA-FULL-VALIDATION.fa.md). بازبینی عامل مستقل جایگزین معلم انسانی، قرارداد کاربرد کودک، بررسی حریم خصوصی، اعتبارسنجی هاست یا پایلوت واقعی نیست. نام فروشنده اثبات هویت مدل بالادستی نیست.
