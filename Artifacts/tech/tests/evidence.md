خروجی ماشینی بررسی‌ها در [validation-report.json](validation-report.json) ثبت می‌شود: پیوندهای محلی، ساختار منابع، شناسه‌های نیازمندی و تسک، parse فایل JSON، انطباق رنگ‌ها با CSS محاسبه‌شده، رندر گالری/وایرفریم و نبود سرریز در عرض‌های آزمون‌شده. نماهای رابط با state ساختگی ساخته شده‌اند؛ عملیات نوشتن در این نماها به سرویس واقعی متصل نیست.

## شکاف‌های شناخته‌شده

۱. `docs/RESTORE.fa.md` در دو محل PHP 8.4 می‌گوید؛ Composer و راهنمای اصلی PHP 8.2+ را مبنا دارند. این تعارض در آرتیفکت‌ها پنهان نشده و TASK-02 برای اصلاح اصل سند پیشنهاد شده است.

۲. تست امنیتی مستقل، آزمون بار، اندازه‌گیری RTO، آزمون صفحه‌خوان و ارزش‌سنجی خانوادگی ثبت نشده‌اند.

۳. اسکریپت package فعلی Artifacts را در بستهٔ source نمی‌گنجاند؛ ZIPهای موجود نیز به‌خاطر این مستندسازی بازتولید نشده‌اند.

۴. نمونهٔ برنامه‌ریز هفتگی در work وجود دارد؛ مسیرها و UI محصول فعلی شاهد ادغام آن نیستند. به دامنهٔ نسخهٔ ۱ اضافه نشده است.

۵. نام مسئول نگه‌داری TLS، برنامهٔ نگه‌داری داده و نسخهٔ backup بیرون از هاست ثبت نشده‌اند.

۶. هنگام رندر محلی این مجموعه، URL قلم‌های build اصلی `/assets/...` بود اما فایل‌ها در `public/assets/build/assets/` قرار داشتند. فقط CSS کپی‌شدهٔ Artifacts به URL نسبی تبدیل شد تا قلم واقعی در گالری و snapshotها بارگذاری شود. رفع build اصلی در TASK-11 ثبت شده است؛ این مشاهده به معنی تأیید خرابی قلم روی سایت تولید نیست.
