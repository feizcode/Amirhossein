# برنامهٔ آزمون فنی و محصول

مرجع نیازمندی: [PRD](../../product/PRD.md) • مرجع اجرا و محدودیت شواهد: [evidence](evidence.md)

## لایه‌ها و محیط‌ها

| لایه | ابزار / داده | هدف و مرز پوشش |
|---|---|---|
| منطق دامنه و تقویم | `php tests/run.php`؛ SQLite حافظه‌ای و پوشهٔ موقت بکاپ | قواعد، dedup، تاریخ، منبع و restore؛ رفتار MariaDB/Apache را اثبات نمی‌کند |
| یکپارچگی مرورگر | `node tests/browser.cjs`؛ Playwright + PHP bridge و SQLite توسعه | UI، API واقعی Slim، نشست، امنیت پایه و عرض ۳۲۰/۳۹۰؛ شبکه و redirect از adapter عبور می‌کنند |
| ساخت و بسته | Composer، Vite، ZIP و manifest | نصب سازگار، assets و نبود راز/دادهٔ تست |
| محیط هاست | smoke روی محیط جدا یا با برنامهٔ دادهٔ دقیق | TLS، Apache، افزونهٔ PHP، MariaDB، document root و دانلود خصوصی |
| بازیابی | بکاپ ساختگی در DB جدا | تطبیق داده، تاریخ، منبع بایگانی و پیشرفت پس از restore |
| تجربه و دسترس‌پذیری | مشاهدهٔ کاربر، صفحه‌کلید، صفحه‌خوان و بررسی دیداری | فهم پیشرفت، داوطلبانه‌بودن چالش و خوانایی؛ اجرای جامع هنوز ثبت نشده |

## روش اجرای کنترل‌شده

پیش‌نیازها از README: PHP 8.2+ با افزونه‌های لازم، vendor، Node و assets ساخته‌شده. مسیر اجرایی PHP/Chrome و Playwright ممکن است محلی باشند؛ به محیط خود تنظیم شوند. برای اجرای مرورگر در رایانه‌ای دیگر `PHP_BIN`، `PLAYWRIGHT_MODULE` و `CHROME_PATH` قابل استفاده‌اند.

```text
composer install
pnpm install --frozen-lockfile
pnpm build
php tests/run.php
node tests/browser.cjs
```

**اثر جانبی مهم:** آزمون مرورگر `tests/reset-local.php` را اجرا و دادهٔ SQLite توسعه را بازنشانی می‌کند و فایل‌های موقت/تصاویر می‌نویسد. آن را روی دفتر واقعی یا تنظیمات تولید اجرا نکنید؛ قبل از اجرا توسعهٔ محلی ارزشمند را حفظ و `environment=development` و DSN مستقل را بررسی کنید. آزمون دامنه از SQLite حافظه‌ای استفاده می‌کند.

در این کار مستندسازی، آزمون بازنشانی‌کنندهٔ مرورگر و smoke تولید دوباره اجرا نشده‌اند. ارزیابی محلی گالری‌ها دادهٔ ساختگی دارد و پایگاه موجود را تغییر نمی‌دهد.

## سناریوهای کلیدی

- یک موضوع، دو فعالیت کامل: شمارش یک؛ دو منبع، موضوع مشترک: شمارش مستقل؛ ویرایش تکمیل/موضوع: بازمحاسبه.
- انجام تکلیف و فعالیت مرتبط: وضعیت تکلیف تغییر و پیشرفت منبع ثابت؛ تغییر کامل/ناقص در UI.
- ویرایش extra/challenge با تاریخ تازهٔ ارسالی: تاریخ اصلی ثابت؛ فعالیت معمولی طبق ورودی معتبر ویرایش می‌شود.
- هفتهٔ شنبه/جمعه، ماه شمسی، مرز سال، اسفند کبیسه، ارقام فارسی/عربی و آیندهٔ نامجاز.
- منبع با سرفصل مشترک/اختصاصی، عنوان بلند، نام تکراری، بیش از ۱۵۰ موضوع و بایگانی آخرین منبع.
- ورود بدون نشست، CSRF نامعتبر، بخش نامتناسب، تلاش مکرر، خروج و متن دارای HTML؛ دانلود بدون احراز هویت و نام فایل نامعتبر.
- متن بلند، صفر رکورد، شبکهٔ قطع، 401، 419 و خطای ذخیره؛ دکمهٔ disabled و حفظ دادهٔ فرم.
- پشتیبان در نخستین استفادهٔ روز، عدم بازنویسی همان روز، نگه‌داری ۷ فایل، قالب خراب، restore تراکنشی و حفاظت تنظیم خصوصی.

وجود سناریو در این فهرست مساوی پوشش خودکار نیست. وضعیت دقیق هر نیازمندی و شکاف‌ها در [ماتریس](acceptance-matrix.md) آمده است.

## معیار انتشار و ثبت نتیجه

آزمون‌های مناسب تغییر باید پاس شوند؛ برای تغییر DB/backup، restore روی DB جدا لازم است. برای تغییر زیرساخت، شواهد محلی کافی نیست. خروجی آزمون باید تاریخ، نسخهٔ کد/هش بسته، محیط، فرمان، شمار checks و نقص‌های باز را ثبت کند. ادعای «امنیت کامل» یا «همهٔ مرورگرها» با مجموعهٔ فعلی قابل دفاع نیست.

بازرسی دیداری: ورود، دفتر خالی/داده‌دار، فرم، درس، والدین، گزارش و پشتیبان در دسکتاپ و موبایل. [گالری محلی](../../design/app-web-design/index.html) مرجع بصری نسخهٔ تدوین مستندات است و تست عملکرد محصول محسوب نمی‌شود.
