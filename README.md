# کشف؛ دفتر یادگیری امیرحسین

برنامهٔ خانوادگی فارسی و راست‌به‌چپ با طرح روشن Material 3. بک‌اند PHP 8.2+ / Slim 4، قالب Twig 3، Alpine CSP و PDO؛ پایگاه دادهٔ تولید MariaDB و پایگاه دادهٔ آزمون محلی SQLite است.

## قابلیت‌ها

- هفت درس (شامل ریاضی کانگورو) و منابع اولیه با سرفصل‌های معین؛ منابع تازه با سرفصل مشترک یا اختصاصی با امکان ویرایش.
- دفتر فعالیت، تحویل تکلیف، مطالعهٔ بیشتر و چالش اختیاری؛ امکان ویرایش و حذف تکالیف، فعالیت‌ها و چالش‌ها.
- پیشرفت مستقل بر پایهٔ موضوع‌های کامل‌شدهٔ متمایز؛ درصد نشانهٔ تسلط نیست.
- فضای والدین برای تکلیف، منابع، گزارش هفتهٔ جاری، هفتهٔ قبل، ماه شمسی قبل و بکاپ‌ها.
- یک رمز خانوادگی، نشست سمت سرور، CSRF، محدودیت تلاش ورود، خروجی امن و PDO پارامتری.
- بکاپ فشردهٔ خصوصی در اولین بارگذاری دفتر در هر روز، با نگهداری هفت نسخه.

انتخاب والدین/امیرحسین فقط گردش کار را جدا می‌کند. همهٔ دارندگان رمز می‌توانند بخش را تغییر دهند. مربی هوشمند و نشان‌ها پیش‌نمایش آینده‌اند؛ تماس با سرویس AI انجام نمی‌شود.

گزارش آخرین آزمون‌های واقعی مدل‌ها و محدودیت‌های باقی‌مانده: [ارزیابی OpenRouter](docs/OPENROUTER-VALIDATION.fa.md) و [آزمون محدود GapGPT](docs/GAPGPT-LIVE-VALIDATION.fa.md) و [آزمون کامل بانک با Luna](docs/LUNA-FULL-VALIDATION.fa.md).

## مدل منتخب: Luna از GapGPT

طبق تصمیم کاربر، `gpt-6-luna` مدل منتخب توسعه است. [تنظیمات و شروط فعال‌سازی](docs/LUNA-SETUP.fa.md) را ببینید. پیش‌فرض تماس زنده خاموش است؛ [تصمیم انتشار بتا و بررسی‌های آینده](docs/BETA-ROLLOUT.fa.md) حالت opt-in را بدون ثبت تأیید صوری توضیح می‌دهد. انتخاب مدل به معنی تأیید همهٔ خروجی‌های آینده نیست. [استقرار بتا روی سرور انجام شد](docs/HOST-BETA-DEPLOYMENT.fa.md)؛ تماس خروجی GapGPT از هاست هنوز با DNS/timeout مواجه است و پاسخ ذخیره‌شده جایگزین می‌شود.

## زنجیرهٔ مدل‌های رایگان OpenRouter (گزینهٔ قبلی/اختیاری)

امکان استفاده از زنجیرهٔ جایگزین فقط با مدل‌های رایگان در `docs/OPENROUTER.fa.md` توضیح داده شده است. این سازوکار از آرایهٔ رسمی `models` در OpenRouter استفاده می‌کند، تعرفهٔ مثبت و مدل پولی را مسدود می‌کند و در صورت شکست به متن ذخیره‌شده بازمی‌گردد. بررسی تعرفه با `bin/openrouter-free-models.php` انجام می‌شود؛ فعال‌سازی نیازمند کلید خصوصی و ثبت تأیید محتوا است.

## نمونهٔ تمرین امروز (مرحلهٔ اول V1)

طراحی جریان، محدودیت‌ها و چک‌لیست ارزیابی در [docs/PRACTICE-V1.md](docs/PRACTICE-V1.md) است. برای نمایش نمونه، در تنظیمات خصوصی `config/local.php` مقدار `practice_prototype_enabled` را `true` کنید و به `/practice-prototype` بروید. پیش‌فرض خاموش است. ۳۲ سؤال با پاسخ‌های بررسی‌شدهٔ محاسباتی آماده است (۱۰ سؤال اولیه و ۲۲ سؤال تکمیلی از مباحث ابتدایی کتاب)؛ تأیید انسانی هنوز لازم است. انتخاب سؤال فقط از مباحث دارای سابقهٔ کتاب درسی در همین پایگاه داده انجام می‌شود؛ کمبود پوشش روی صفحه اعلام می‌شود. زیرساخت AI با سقف مصرف و جایگزین ذخیره‌شده آماده است، اما تماس زنده تا تأیید مدل خاموش است. برای پایلوت، `practice_allow_prototype_content` باید صریحاً `true` باشد؛ در حالت انتشار فقط محتوای دارای تأیید انسانی پذیرفته می‌شود. [وضعیت انتشار](docs/PRACTICE-RELEASE.fa.md) را ببینید. جلسه‌ها، تلاش‌ها و کمک‌های دریافت‌شده در پایگاه داده می‌مانند؛ دفتر مرور و گزارش واقعی تمرین والدین اضافه شده‌اند. مرور اولیه پس از ۲ روز است و پاسخ مستقل به سؤال مشابه، مرحله‌های ۷ و ۱۴ روزه را فعال می‌کند. این نتایج از درصد تکمیل منابع جدا هستند.

```sh
php -n tests/practice-content.php
php -n tests/practice-extension.php
php -n tests/practice-v1-content.php
php -n tests/practice-prototype.php
php tests/practice-persistence.php
php tests/practice-backup.php
php tests/practice-http.php
php tests/ai-coach.php
node tests/practice-browser.cjs
php bin/export-sql.php
```

## توسعه

PHP 8.2+ با `pdo`, `pdo_mysql`, `pdo_sqlite`, `mbstring`, `intl`, `zlib`, `session` و Composer؛ Node.js 20.19+ یا 22.12+ و pnpm 10 لازم است.

```sh
composer install
pnpm install --frozen-lockfile
pnpm build
php bin/local-setup.php
php -S 127.0.0.1:8088 -t public public/router.php
```

رمز موقت توسعه فقط در `work/test-credentials.json` نوشته می‌شود و وارد بستهٔ انتشار نمی‌شود. پایگاه دادهٔ توسعه در `work/development.sqlite` است. برای ساخت تنظیمات تولید، [راهنمای استقرار](docs/DEPLOYMENT.fa.md) را بخوانید.

## آزمون و بسته‌بندی

```sh
php tests/run.php
node tests/browser.cjs
php bin/export-sql.php
pnpm build
node bin/package.cjs
```

آزمون مرورگر به Playwright و Chrome نیاز دارد؛ مسیر کتابخانه با `PLAYWRIGHT_MODULE` قابل تنظیم است. همهٔ درخواست‌های این آزمون آفلاین به خود برنامهٔ PHP هدایت می‌شوند؛ داده‌های SQLite محلی را بازنشانی می‌کند و به سرور تولید وصل نمی‌شود. تغییر مسیر HTTP در این سازوکار با انتقال داخلی نمایش داده می‌شود؛ آزمون واقعی Apache، TLS و MariaDB باید پس از استقرار نیز انجام شود.

بستهٔ انتشار شامل وابستگی‌های Composer و فایل‌های ساخته‌شدهٔ رابط است؛ در هاست به Composer، Node، Cron یا پردازش دائمی نیاز ندارد. اطلاعات اتصال، رمز، دادهٔ نمونه، ابزارهای توسعه و SQLite در بسته قرار نمی‌گیرند.

## API

همهٔ مسیرهای `/api/v1` به نشست معتبر نیاز دارند. درخواست نوشتن به هدر `X-CSRF-Token` نیاز دارد؛ مقدار آن در صفحهٔ خصوصی با متای `csrf-token` وجود دارد.

| مسیر | روش | کاربرد |
|---|---|---|
| `/state` | GET | وضعیت مشترک دفتر و سرفصل‌ها |
| `/context` | POST | انتخاب گردش کار کودک/والدین |
| `/activities` و `/{id}` | POST / PUT / DELETE | ثبت، ویرایش و حذف فعالیت |
| `/assignments` و `/{id}` | POST / PUT / DELETE | ثبت، ویرایش و حذف تکلیف در بخش والدین |
| `/assignments/{id}/complete` | POST | تغییر انجام تکلیف توسط کودک |
| `/extra-studies` و `/{id}` | POST / PUT | گزارش مطالعهٔ بیشتر |
| `/challenges` و `/{id}` | POST / PUT / DELETE | ثبت، ویرایش و حذف چالش درسی یا روزمره |
| `/resources` و `/{id}` | POST / PUT | ثبت و ویرایش منبع در بخش والدین |
| `/resources/{id}/archive` | POST | بایگانی منبع با حفظ سابقه |
| `/reports?period=current_week` یا `week` یا `month` | GET | گزارش هفته جاری یا بازه‌های قبل |
| `/backups` و `/{name}` | GET | فهرست و دانلود خصوصی پشتیبان |

تاریخ ورودی `۱۴۰۵/۰۷/۲۸` یا ISO پذیرفته می‌شود؛ ذخیرهٔ تاریخ میلادی است. تمام مرزهای تقویمی با `Asia/Tehran` محاسبه می‌شوند. پیشرفت در مرورگر ذخیره نمی‌شود؛ `sessionStorage` فقط صفحه و منبع انتخاب‌شده را نگه می‌دارد.
